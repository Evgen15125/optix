## ВАЖНО ПРОЧИТАТЬ ПЕРЕД ИСПОЛЬЗОВАНИЕМ

Optix — инструмент для **опытных пользователей**. Некоторые функции
изменяют системные настройки (реестр, службы, планировщик задач).

- Программа предоставляется **«как есть»**.
- Автор **НЕ несёт ответственности** за повреждения системы, потерю
  данных или снижение производительности.
- **ПЕРЕД использованием** оптимизации и изменения служб **создайте
  точку восстановления системы** (раздел «Очистка» — «Точки
  восстановления»).
- Требуются **права администратора**.
- Используйте **на свой страх и риск**.

## Что умеет Optix

12 разделов:

1. **Очистка** — 38 категорий мусора, профили, история, куки,
   дубликаты, реестр, точки восстановления, Dry-Run.
2. **Мониторинг** — CPU/RAM/диски/сеть, GPU, батарея, TCPView,
   DPC/ISR, история температур, трафик по адаптерам.
3. **Автозапуск** — Run/RunOnce/Startup/Scheduler, оценка влияния,
   аудит baseline.
4. **Службы** — вкладки, зависимости, экспорт/импорт JSON.
5. **Оптимизация** — 16 твиков, Live-Tuner, NTFS, реклама,
   гибернация, DNS.
6. **Диски** — SMART, TRIM, дефраг, Treemap, NO_BUFFERING,
   проверка поверхности, снимки диска.
7. **Диагностика** — SFC, DISM, BSOD, DPC/ISR, Boot Repair, PDF,
   аудит безопасности, сброс сети, умный анализ журнала.
8. **Бенчмарки** — 23 теста, 5 профилей.
9. **Программы** — полное удаление, портативные, наблюдение за
   установкой.
10. **Драйверы** — WUA + Microsoft Catalog, Driver Store,
    PnP-устройства, онлайн-поиск.
11. **Планировщик** — задачи, триггеры, условия, действия, история,
    шаблоны, скрипты.
12. **Отчёты** — TXT, HTML, PDF, JSON, Markdown, диагностика
    Windows, инвентаризация, Diff.

## Системные требования

- **Windows 10 или Windows 11** (x64)
- **Python 3.10 – 3.12** (рекомендуется 3.11 или 3.12)
- **Права администратора**
- ~500 МБ свободного места

Python 3.13 и 3.14 могут иметь проблемы с частью библиотек
(pywin32, wmi). Если что-то не работает — используйте 3.11.

## Установка

### Шаг 1. Установите Python

Скачайте Python **3.11** или **3.12** с https://www.python.org/downloads/

При установке **обязательно** отметьте галочку **«Add Python to PATH»**.

### Шаг 2. Распакуйте архив

Распакуйте `optix.zip` в удобную папку, например `D:\Optix\`.

### Шаг 3. Установите зависимости

Запустите **`install.bat`** двойным кликом. Дождитесь сообщения
«ГОТОВО».

### Шаг 4. Запустите Optix

Запустите **`run_optix.bat`** двойным кликом.

При первом запуске:
- появится окно UAC — нажмите «Да»;
- появится дисклеймер — прочитайте и подтвердите.

## FAQ

**Антивирус ругается на Optix. Что делать?**
Это нормально для программ-оптимизаторов. Добавьте папку в
исключения антивируса.

**Программа требует админа, зачем?**
Многие операции требуют повышенных прав. Без этого половина функций
не работает.

**Температуры не показываются.**
Установите OpenHardwareMonitor и положите его в
`C:\Program Files\OpenHardwareMonitor\`.

**Как откатить изменения?**
Все изменения реестра сохраняются в JSON-бэкапы. В разделе
«Оптимизация» есть кнопка «Откатить всё».

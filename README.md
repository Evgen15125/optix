# 🚀 Optix

Многофункциональная программа для оптимизации и обслуживания Windows.

## ✨ Возможности
- Очистка мусора и кэша
- Мониторинг температуры и нагрузки
- Управление автозапуском и службами
- Встроенный ИИ-ассистент (локальный + DeepSeek)
- Тёмная тема и плавные анимации

## 📥 Установка
1. Скачайте последний релиз из раздела **Releases**.
2. Запустите `Optix.exe`.

## 🛠️ Для разработчиков
Требуется Python 3.14+ и библиотеки:
`pip install -r requirements.txt`

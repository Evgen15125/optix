# Changelog

\## \[1.8.6] — 2026-10-29



\### Исправлено (по итогам аудита №5)

\- \*\*P1:\*\* гонка при быстром сворачивании/разворачивании окна из трея: несколько параллельных `\_ensure\_ohm\_running()` могли запустить несколько экземпляров OpenHardwareMonitor и перезаписать PID в `\_OHM\_STARTED\_BY\_US` (лишний OHM переживал выход из Optix). Добавлен `\_OHM\_ENSURE\_LOCK` (non-blocking acquire).

\- \*\*P2:\*\* `\_do\_show\_window`: `except Exception: pass` заменён на `log\_error("\_do\_show\_window", e)` — тихие сбои восстановления окна теперь видны в логе.

\- \*\*P2:\*\* экспорт отчёта мониторинга: в имя файла добавлены секунды (`%H-%M-%S`) — два экспорта подряд в пределах минуты больше не перезаписывают друг друга.



\### Проверено и оставлено как есть

\- `\_safe\_startfile` (без рекурсии), `\_open\_disk\_management` (SystemRoot — локали-независим), `\_get\_system\_extended` (восстановлена, дублей нет), фоновый экспорт отчёта (Tk через `app.after`).

Все значимые изменения проекта фиксируются здесь.
